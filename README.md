---

## 2. Membuat Struktur Dasar HTML

Saya membuat file `index.html` dan menambahkan struktur dasar HTML yang terdiri 
dari `<!DOCTYPE html>`, `<html>`, `<head>`, dan `<body>`.

Struktur dasar yang digunakan:

```html
<!DOCTYPE html>
<html>
<head>
    <title>Praktikum HTML Dasar</title>
</head>
<body>
</body>
</html>
